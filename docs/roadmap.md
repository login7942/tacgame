## 🎯 현재 게임 상태 분석

### ✅ 잘 구현된 부분
- 자동화 시스템 (전투, 채집)
- 대량 제작 시스템
- 기본 제작-장비 루프
- 일꾼 시스템
- 시장 시스템 (기본)
- 계승 시스템

### ⚠️ 부족하거나 개선 필요한 부분

#### 1. 재료 순환이 약함
**문제:**
- 저티어 재료가 후반에 쓸모없어짐
- 재료 소비처가 부족 (만들면 끝)
- 자원이 계속 쌓이기만 함

**결과:** 채집/제작의 동기 부여 감소

#### 2. 시장이 너무 단순함
**문제:**
- 무한 구매 가능 (구매 제한 없음)
- 가격 변동이 의미 없음
- 투자/투기 요소 전무
- 시장 활용도가 낮음

**결과:** 골드의 가치 하락, 전략적 깊이 부족

#### 3. 장비가 일회성임
**문제:**
- 만들면 끝, 업그레이드 없음
- 강화/인챈트/세트 효과 없음
- 같은 장비 여러 개 만들 이유 없음

**결과:** 장비 제작의 목표 상실

#### 4. 리스크/보상 구조 없음
**문제:**
- 모든 행동이 100% 안전
- 도박/투자 요소 전무
- 실패가 없어서 긴장감 부족

**결과:** 게임이 단조로워짐

#### 5. 중독성 요소 부족
**문제:**
- 도감/업적 없음
- 일일 목표 없음
- 컬렉션 욕구 자극 부족

**결과:** 장기 리텐션 약함

## 🔥 Hot Phase: 핵심 재미 구축 (최우선)

### H-1. 장비 강화 시스템 ⭐⭐⭐⭐⭐ 🔧 진행중
**왜 중요한가:**
- 저티어 재료 순환 (강화석으로 사용)
- 리스크/보상 구조 (실패 가능성)
- 장기 목표 제공 (+10 도전)
- 골드 소비처 (강화 비용)

**구현 상세:**
```
강화 레벨: +0 ~ +10
성공률:
  - +1: 95%
  - +2: 90%
  - +3: 85%
  - +4: 80%
  - +5: 75%
  - +6: 65%
  - +7: 50%
  - +8: 40%
  - +9: 30%
  - +10: 20%

실패 시:
  - +0~+5: 강화도 유지
  - +6~+7: 50% 확률로 강화도 -1
  - +8~+10: 강화도 -1 또는 30% 확률로 파괴

재료:
  - 강화석 (저티어 광석 3개로 제작)
  - 골드 (강화 레벨당 100G * 레벨)

보너스:
  - 레벨당 스탯 +5~10%
  - +5: 빛나는 효과
  - +10: 전설적 빛 효과
```

### H-2. 시장 구매 제한 + 투자 시스템 ⭐⭐⭐⭐⭐
**왜 중요한가:**
- 채집/일꾼 배치 동기 부여
- 시장 가격 변동이 의미있어짐
- 전략적 깊이 추가

**구현 상세:**
```
일일 구매 한도:
  - 각 아이템: 일일 최대 50개 구매
  - 자정 리셋
  - 초과 구매 시 가격 2배

가격 예측 투자:
  - "내일 철광석 가격이 오를 것 같습니다"
  - 골드 투자 (예: 1000G)
  - 24시간 후 결과 확인
  - 맞으면 +50% 수익
  - 틀리면 -30% 손실

대량 거래 영향:
  - 100개 이상 거래 시 가격 ±10% 즉시 변동
  - 시장 수요/공급 시뮬레이션
```

### H-3. 장비 분해 시스템 ⭐⭐⭐⭐
**왜 중요한가:**
- 불필요한 장비 처리
- 재료 순환 완성
- 제작 실수 보완

**구현 상세:**
```
장비 분해:
  - 제작 재료 50~80% 랜덤 회수
  - 강화된 장비는 강화석도 일부 회수
    (+1~+5: 50% 회수, +6~+10: 70% 회수)
  - 티어 높을수록 보너스 재료
    (가루, 정수 등 추가 드롭)
  - 분해 시간: 즉시
  - 비용: 무료
```

### H-4. 도감 시스템 (기본) ⭐⭐⭐⭐
**왜 중요한가:**
- 컬렉션 욕구 자극
- 장기 목표 제공
- 영구 보너스로 성장 실감

**구현 상세:**
```
3개 카테고리:
  1. 자원 도감 (70+ 자원)
     - 각 자원 최소 1개 수집 시 등록
     - 완성도 표시 (XX/70)

  2. 몬스터 도감 (40+ 몬스터)
     - 각 몬스터 최소 1회 처치 시 등록
     - 처치 횟수 기록
     - 드롭 테이블 표시

  3. 장비 도감 (40+ 장비)
     - 각 장비 최소 1회 제작 시 등록
     - 스탯 정보 표시

완성도 보상:
  - 10%: 골드 획득 +2%
  - 20%: 경험치 획득 +2%
  - 30%: 채집 속도 +2%
  - 40%: 전투 피해 +2%
  - 50%: 특수 칭호 + 스탯 +5
  - 60%: 일꾼 효율 +5%
  - 70%: 시장 수수료 -5%
  - 80%: 레거시 포인트 +10%
  - 90%: 전설 아이템 도안
  - 100%: 완전체 칭호 + 모든 스탯 +10%
```

## 📊 Phase A: 순환 경제 구축

### A-1. 일꾼 유지비 시스템
**목적:** 저티어 음식/재료 지속 소비

```
일꾼 상태 관리:
  - 배고픔: 6시간마다 음식 1개 필요
  - 도구 내구도: 채집 100회마다 도구 수리 필요
  - 미충족 시: 효율 50% 감소

음식 소비:
  - 자동 소비 (인벤토리에서 차감)
  - 없으면 효율 감소 알림

도구 수리:
  - 수리비: 도구 티어에 따라 골드 + 재료
  - 미수리 시: 도구 파손 (재제작 필요)
```

### A-2. 제작 부산물 시스템
**목적:** 재료 순환 촉진

```
제작 시 10% 확률로 부산물 생성:
  - 광석 제련 → 광물 찌꺼기 (비료로 사용)
  - 장비 제작 → 금속 가루 (강화석 재료)
  - 물약 제작 → 빈 병 (재사용 가능)
  - 음식 제작 → 남은 재료 (일꾼 먹이)
```

### A-3. 시장 고급 기능
```
경매 시스템:
  - 희귀 아이템 자동 경매
  - 12시간 입찰 기간
  - 최고 입찰자 낙찰

선물 거래:
  - 미래 가격에 현재 구매 계약
  - 가격 변동 리스크

상인 퀘스트:
  - "철괴 100개 납품 시 2배 보상"
  - 제한 시간 24시간
  - 실패 시 페널티 없음
```

## 🎲 Phase B: 리스크/보상 시스템

### B-1. 원정 시스템
```
원정 설정:
  - 일꾼 1~3명 파견
  - 4/8/12시간 선택
  - 음식, 장비, 골드 투자 필요

성공률 계산:
  - 일꾼 레벨 × 10%
  - 장비 티어 × 5%
  - 음식 품질 × 3%
  - 기본 성공률 50%

결과:
  - 성공: 희귀 재료 + 경험치 2배
  - 실패: 일꾼 부상(3일 휴식) + 자원 50% 손실
  - 대성공(10%): 전설 아이템 + 골드 5배
```

### B-2. 도박 상인
```
랜덤 박스 구매:
  - 청동 상자 (100G)
    → 저티어 재료 10~30개

  - 은 상자 (500G)
    → 중티어 재료 5~15개
    → 10% 확률로 장비

  - 금 상자 (2000G)
    → 고티어 재료 3~10개
    → 30% 확률로 희귀 장비
    → 5% 확률로 전설 아이템

확률 공개 (투명성)
일일 구매 제한 (10개)
```

### B-3. 던전 도전
```
입장료: 스태미나 50 + 골드 1000

난이도 선택:
  - 쉬움: 보상 1배, 실패 없음
  - 보통: 보상 2배, 실패 시 50% 환불
  - 어려움: 보상 3배, 실패 시 손실
  - 지옥: 보상 5배, 실패 시 장비 파손

보상:
  - 경험치, 골드, 희귀 재료
  - 던전 전용 아이템
```

## 🎯 Phase C: 중독성 강화

### C-1. 업적 시스템 (300+ 업적)
```
카테고리별 업적:

전투:
  - "슬라임 1000마리 처치"
  - "노데미지 클리어"
  - "10초 안에 보스 처치"

채집:
  - "철광석 10000개 채집"
  - "연속 채집 100회"
  - "전 지역 자원 수집"

제작:
  - "강화 +10 성공"
  - "전설 장비 제작"
  - "1000개 아이템 제작"

경제:
  - "100만 골드 보유"
  - "시장 투자 10회 성공"
  - "일꾼 10명 고용"

보상:
  - 골드, 레거시 포인트
  - 특수 칭호 (스탯 보너스)
  - 영구 버프
```

### C-2. 일일/주간 미션
```
일일 미션 (매일 리셋):
  - 자원 100개 채집 → 골드 500
  - 몬스터 20마리 처치 → 경험치 보너스
  - 장비 5개 제작 → 강화석 x3
  - 시장 거래 10회 → 무료 상자

주간 미션 (월요일 리셋):
  - 레벨 5 상승 → 레거시 포인트 +10
  - 도감 5% 증가 → 특수 재료
  - 시장 거래 50회 → 무료 투자권
  - 일꾼 레벨 10 달성 → 고급 장비

보상 중복 수령 가능
```

### C-3. 시즌 시스템 (선택)
```
3개월 시즌:
  - 시즌 전용 보상 (스킨, 칭호)
  - 시즌 랭킹 (레벨, 자산, 도감)
  - 시즌 미션 (특별 보상)
  - 시즌 종료 후 레거시 포인트 지급
```

- **경매 시스템** → 희귀 아이템 가치

- **강화 시스템** → 끝없는 성장 목표
- **세트 효과** → 장비 조합 전략
- **분해/재제작** → 실험 가능
- **장비 도감** → 컬렉션 욕구

### 🎲 투자/실패
- **강화 실패** → 긴장감과 도전
- **원정 시스템** → 리스크 선택
- **도박 상인** → 운 요소
- **던전 난이도** → 보상 차등

### 🎯 중독성
- **도감 시스템** → 컬렉션 욕구

## 🏗️ 코드 아키텍처 원칙
- **모듈 분리**: 각 시스템은 `js/systems/` 하위에 독립 모듈
- **낮은 결합도**: 시스템 간 통신은 이벤트/콜백으로만
- **단일 책임**: 한 모듈은 한 가지 역할만
- **점진적 리빌딩**: 기존 코드를 한 시스템씩 분리
- **테스트 가능**: 각 시스템은 독립적으로 테스트 가능
